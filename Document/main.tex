\section{Cypress}
Cypress is modern solution for Web-app testing.
\subsection{setup}
Cypress is written in javascript and so to install we need to use npm which is the package manager of javascript.

\noindent See the following command :
\begin{lstlisting}[language=bash]
  npm init
\end{lstlisting}
\noindent See the following command :
\begin{lstlisting}[language=bash]
  npm install cypress --save-dev
\end{lstlisting}
